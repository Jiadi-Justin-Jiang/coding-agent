Tasks are created by POST /tasks → create_task() in routes/tasks.py:15:                                       

 1 Parses the JSON body with request.get_json(silent=True) or {} (routes/tasks.py:17), so a missing/invalid   
   body becomes {}.                                                                                           
 2 Reads title with a default of "" (routes/tasks.py:18) — no validation, so an empty or whitespace-only title
   is accepted.                                                                                               
 3 Calls TaskStore.add_task() (models.py:44), which assigns the next id from an itertools.count, builds a Task
   with status "todo" and a UTC created_at, and stores it in a dict.                                          
 4 Returns the task as JSON with 201 Created (routes/tasks.py:24).                                            

The store is injected via app.config["STORE"] in create_app() (main.py:12), which is how tests get a fresh    
store per test.
